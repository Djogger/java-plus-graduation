# ExploreWithMe

---

### Общая информация
На текущем этапе разработки единое монолитное приложение было разделено на несколько отдельных микросервисов. Эти сервисы взаимодействуют между собой через API-шлюз с применением технологий Spring Cloud и контейнеризации Docker.

### Архитектура системы
Публичный интерфейс приложения предоставляется через Gateway и соответствует спецификации, разработанной ранее в рамках группового проекта.

Пользовательский запрос -> Шлюз API (порт 8080) -> Необходимый микросервис

text

Дополнительные компоненты:
- **Сервер обнаружения Eureka** - отвечает за автоматическую регистрацию и поиск сервисов
- **Сервер конфигураций** - централизованное хранилище настроек
- **База данных PostgreSQL** - единая СУБД для всех компонентов системы

Весь внешний трафик поступает исключительно через API Gateway на порт 8080, где распределяется по соответствующим сервисам.

### Функциональные модули (микросервисы)
- **Сервис событий (event-service)** - полный цикл работы с событиями: создание, изменение, удаление, поиск
- **Сервис заявок (request-service)** - обработка запросов на участие в событиях
- **Сервис пользователей (user-service)** - управление учетными записями и правами доступа
- **Сервис статистики (stats-service)** - сбор и анализ статистических данных

### Вспомогательные службы
- **Шлюз (gateway-server)** - основной входной узел, перенаправляющий запросы к нужным сервисам
- **Сервер обнаружения (discovery-server)** - механизм динамического обнаружения служб на основе Eureka
- **Сервер конфигураций (config-server)** - централизованное управление настройками всех компонентов системы

### Коммуникация между сервисами
Взаимодействие микросервисов организовано через REST API с использованием клиентов OpenFeign. Клиентские интерфейсы расположены в модуле `core/interaction-api`:

- **Клиент событий (EventClient)** - обращения к сервису событий
- **Клиент заявок (ParticipationRequestClient)** - обращения к сервису заявок
- **Клиент пользователей (UserClient)** - обращения к сервису пользователей

### Настройка и конфигурация
Все параметры системы хранятся централизованно в репозитории конфигураций, обслуживаемом config-server:
infra/config-server/src/main/resources/config/

```shell
docker compose --profile docker up
```

После полного запуска приложение становится доступным по адресу: http://localhost:8080
